# SecureVision – Server Side Storage Model

A secure video encryption and controlled playback system using AES-256-GCM.

## Features

- Password-based video encryption
- Server-side encrypted storage
- Secure in-memory playback
- Zero-trust key handling

## Tech Stack

- Python (Flask)
- AES-GCM (Cryptography)
- HTML5 + JavaScript
